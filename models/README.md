# Model Artifacts

Model binaries are generated by the reproducible pipeline and are intentionally not committed to Git because they are build artifacts.

Run:

```bash
python src/pipeline.py
```

This creates:

- `baseline_fp32.pt`
- `baseline_fp32_state_dict.pth`
- `pruned_fp32.pt`
- `pruned_fp32_state_dict.pth`
- `quantized_int8.pt`
- `pruned_quantized_int8.pt`

Then run:

```bash
python src/export_onnx.py
```

to generate the ONNX/INT8 edge-runtime artifacts and ONNX Runtime benchmark outputs.
